Docker Contexts

Configure where challenge containers run. By default, containers spin up on the same machine as CTFd. Add Docker contexts to run containers on remote servers instead.

When creating container-type challenges, you can specify which context to use. CTFd will list available Docker images from that context, let you configure container settings, and automatically expose a random port to users.
